** What is Resurface?
Resurface is an Emacs package for keeping long-form knowledge familiar over time through scheduled rereading.

Unlike traditional spaced repetition systems, Resurface is *not* designed around active recall or flashcards. Instead it treats rereading as a continuous process of /maintaining familiarity/. Every review contributes *evidence* about how well a note is understood, and that evidence is accumulated over multiple sessions before future review intervals are adjusted.

** Installation with =package-vc-install= (emacs 29+)
 Add the following to your ~init.el~:

 #+BEGIN_SRC emacs-lisp
    (use-package resurface
      :vc (:url "https://github.com/vmargb/resurface.el")
      :bind ("C-c r l" . resurface-leitner)
      :bind ("C-c r d" . resurface-drill))
 #+END_SRC

*** Example Customization
 #+BEGIN_SRC emacs-lisp
 (setq resurface-index-file "~/notes/.resurface-index.json") ; change location
 (setq resurface-leitner-intervals [1 2 4 8 16 32]) ; set your own ideal intervals
 (setq resurface-leitner-default-group "General") ; default when group not provided
 (setq resurface-enable-drill-mode t) ; require resurface-drill.el

 ;; Familiarity Scheduler tuning, these are all optional
 (setq resurface-leitner-history-length 5) ; ratings kept per item
 (setq resurface-leitner-weighting 'linear) ; linear | exponential | uniform
 (setq resurface-leitner-promote-threshold 0.80)
 (setq resurface-leitner-demote-threshold -0.40)
 (setq resurface-leitner-reset-threshold -0.80)
 (setq resurface-leitner-interval-tolerance 0.20) ; +/- 20% scheduling slack around the ideal
 (setq resurface-leitner-workload-weight 1.0) ; 0 disables workload-awareness
 #+END_SRC

** Modified Leitner mode
The classic Leitner box system has been modified to use a /familiarity scheduler/. You can read more about the original Leitner system [[https://en.wikipedia.org/wiki/Leitner_system][here]].

Ratings are instead *Familiar* / *Unfamiliar* rather than Good/Bad, reading back a long-form note is no longer a recall test. Two more ratings cover the practical edges of rereading:

- /Partial/: For files too long to finish reading in one sitting. The file is *paused* and comes due again the next day so you can pick up where you left off. Works well with =save-place-mode=.
- /Revised/: For when you *edited* or *added new content*. Box stays untouched, but the review counts as complete, so the file returns on its normal box interval rather than tomorrow.
- /Skip/: Leaves the file in its current box without altering its schedule.

*** How the Familiarity Scheduler works
#+begin_quote
Familiarity ratings
        |
        v
Weighted confidence estimate
        |
        v
Desired review interval
        |
        v
Workload-aware scheduler
#+end_quote

A single session's rating is a noisy one-off read on how a file feels, which is an unreliable measurement. This was a big weakness of Leitner. So now, no single Good/Bad rating moves the box directly. Instead:

1. Every rating is appended to a short rolling history (=resurface-leitner-history-length=, default 5).
2. That history becomes a *confidence score* from -1 to +1, a recency-weighted average (=resurface-leitner-weighting=: =linear= by default, or =exponential=/=uniform=).
3. The box only moves when the confidence score clears a threshold: =resurface-leitner-promote-threshold= (default 0.80) promotes one box (or graduates, from the last box). Anywhere between demote and promote, the file just stays put. 
4. Each box is now an *ideal* interval rather than an exact deadline. The scheduler looks at every day within =resurface-leitner-interval-tolerance= (default +/-20%) of that ideal and self-balances by picking whichever is least crowded with other reviews (=resurface-leitner-workload-weight=). This is actually used in distributed computer systems. If thousands of servers all retry at exactly 10 seconds, they overload the network

The explicit "reset to Box 1" action (=r= in the detail/graduated views) always goes straight to Box 1 and clears the history, regardless of current confidence, which manually overrides the existing scheduling.

*** Optional question prompts
Though this is built around reviewing long-form documents, you /can/ *optionally* add specific question prompts with =#+LEITNER_PROMPT:= at the top of an org file to create standard Q&A flashcards. Otherwise it will fallback to your =#+TITLE:=. Or just leave this empty and it will ignore the prompt entirely.


** Drill Mode: rereading sentences, not testing recall
Drill mode is a *second, parallel* review system, built specifically for language learning (but can be generalized for anything else). The idea comes from the book *Henle's Latin* where you practice re-reading the same sentence many many times until the meaning naturally /emerges/ out of the repetiton. There is no hidden "answer" to reveal, and no good/bad rating. Every session you just say whether a sentence feels *opaque* or if it feels *clear* yet.

Drill mode lives in its own file, =resurface-drill.el=, loaded automatically the first time you call one of its commands (see =resurface-enable-drill-mode= if you'd rather it load up front instead).

 | Keybinding                       | Command                       | Description                                    |
 |-----------------------------------+--------------------------------+-------------------------------------------------|
 | =M-x resurface-drill=                 | =resurface-drill=                 | Open the drill block dashboard.                |
 | =M-x resurface-drill-add-block=       | =resurface-drill-add-block=       | Add a new drill block.                         |
 | =M-x resurface-drill-add-sentence=    | =resurface-drill-add-sentence=    | Add a sentence/chunk to a block.               |
 | =M-x resurface-drill-add-lines-from-region= | =resurface-drill-add-lines-from-region= | Add every non-blank line in the region as its own sentence. |
 | =M-x resurface-drill-start-session=   | =resurface-drill-start-session=   | Drill all due sentences (=C-u=: one block).      |
 | =M-x resurface-drill-review-retired=  | =resurface-drill-review-retired=  | Browse retired sentences; bring any back to Active. |

*** Adding sentences
=resurface-drill-add-sentence= (and the =e= edit command in a block's
detail view) no longer type into the minibuffer. Instead they open a
small dedicated buffer to write or paste into: normal editing commands,
multi-line paste, and =evil-mode= all work there like any other buffer.
Press =C-c C-c= to accept, =C-c C-k= to discard. When adding, write one
sentence per line; every non-blank line becomes its own drill item in
the chosen block, so pasting several sentences at once adds them all.

*** How it works
A drill item is scored on how much saturated exposure it has had. Sentences move through three modes instead of numbered boxes:

=active -> stabilizing -> maintenance -> retired=

During a drill session, the sentence is shown directly (no reveal step) with three ratings:
- /Clear/: arrived at understanding, counts toward promotion.
- /Opaque/: still needs work, resets the streak, resurfaces tomorrow.
- /Retire now/: force-retire immediately, regardless of thresholds.
- /Skip/: leave the sentence untouched.

Movement needs *both* enough consecutive =Clear= outcomes (=resurface-drill-promote-exposures=, default 3) *and* a minimum number of days having passed in that mode (=resurface-drill-min-days-per-mode=, default 3, that stops an easy sentence graduating on day one). An =Opaque= outcome resets that streak to zero and always brings the sentence back tomorrow, regardless of its mode's normal interval. If it happens in =maintenance=, the sentence also demotes straight back to =active=, if it got rusty.

You can also batch-retire an entire block at once from its detail view (=R=), rather than only ever retiring one sentence at a time.

*** Example Customization
#+BEGIN_SRC emacs-lisp
(setq resurface-drill-intervals '((active . 1) (stabilizing . 4) (maintenance . 14))) ; days between resurfacing, per mode
(setq resurface-drill-promote-exposures 3) ; consecutive Clear outcomes needed to advance a mode
(setq resurface-drill-min-days-per-mode 3) ; mandatory minimum days spent in a mode before advancing
(setq resurface-drill-default-block "General")
#+END_SRC

** Changelog
- /v0.2.0:/ Full rewrite based around a *Familiarity Scheduler*: ratings are now Familiar/Unfamiliar, building a rolling recency-weighted confidence score rather than moving the box on a single rating. Boxes are now ideal intervals, not deadlines, next-review dates are chosen from a small window around the ideal to spread load across quieter days. 
- /v0.1.0:/ Standard Leitner box implementation with extra features: random box shuffling, rename groups, healthcheck, batch add files through dired, graduated-file-browser, partial and revised ratings and resurface-drill.
