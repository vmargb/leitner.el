** What is Resurface?
=resurface.el= is an Emacs package that brings material back for review on a schedule instead of leaving it to whenever you happen to remember it exists. =Leitner-mode= applies the classic =Leitner box system= to your note-taking workflow, this is for /re-reading/ your *longer-form* notes and /revising/ them, not for active recall (though it can be used that way). Drill-mode does the same but for *short* sentences/chunks you want to practice rereading /repeatedly/, *not* recalling them.

Simply use =resurface-leitner-add-file= which handles when to /resurface/ the file for your next re-reading/revising session.

** Installation with =package-vc-install= (emacs 29+)
 Add the following to your ~init.el~:

 #+BEGIN_SRC emacs-lisp
    (use-package resurface
      :vc (:url "https://github.com/vmargb/resurface.el")
      :bind ("C-c r l" . resurface-leitner)
      :bind ("C-c r d" . resurface-drill))
 #+END_SRC

** How Leitner Works
Each box has a defined review interval (Box 1 = 1 day, Box 2 = 3 days). Once a file reaches the final box and is rated "Good," it /graduates/ and is removed from the review queue.

Whenever a file is due, you review and rate your recall confidence:
- /Good/: Box 4 file -> moves to Box 5. 
- /Bad/: drops back down to Box 1 (forgot important details, note felt unfamiliar or required heavy revising).

*There are a couple new options designed for the nuances around reading:*
- /Partial/ (new): For files too long to finish reading in one sitting. The file is *paused* and comes due again the next day so you can pick up where you left off. Works well with =save-place-mode=.
- /Revised/ (new): For when you *edited* or *added new content* stays in the same box, but is due tomorrow instead.
- /Skip/: Leaves the file in its current box without altering its schedule.

*** Optional question prompts
Though this is built around reviewing long-form documents, you /can/ *optionally* add specific question prompts with =#+LEITNER_PROMPT:= at the top of an org file to create standard Q&A flashcards. Otherwise it will fallback to your =#+TITLE:=. Or just leave this empty and it will ignore the prompt entirely.


** Drill Mode: rereading sentences, not testing recall
Drill mode is a *second, parallel* review system, built specifically for language learning (but can be generalized for anything else). The idea comes from the book *Henle's Latin* where you practice re-reading the same sentence many many times until the meaning naturally /emerges/ out of the repetiton. There is no hidden "answer" to reveal, and no good/bad rating. Every session you just say whether a sentence feels *opaque* or if it feels *clear* yet.

 | Keybinding                       | Command                       | Description                                    |
 |-----------------------------------+--------------------------------+-------------------------------------------------|
 | =M-x resurface-drill=                 | =resurface-drill=                 | Open the drill block dashboard.                |
 | =M-x resurface-drill-add-block=       | =resurface-drill-add-block=       | Add a new drill block.                         |
 | =M-x resurface-drill-add-sentence=    | =resurface-drill-add-sentence=    | Add a sentence/chunk to a block.               |
 | =M-x resurface-drill-add-lines-from-region= | =resurface-drill-add-lines-from-region= | Add every non-blank line in the region as its own sentence. |
 | =M-x resurface-drill-start-session=   | =resurface-drill-start-session=   | Drill all due sentences (=C-u=: one block).      |
 | =M-x resurface-drill-review-retired=  | =resurface-drill-review-retired=  | Browse retired sentences; bring any back to Active. |

*** How it works
A drill item is scored on how much saturated exposure it has had. Sentences move through three modes instead of numbered boxes:

=active -> stabilizing -> maintenance -> retired=

During a drill session, the sentence is shown directly (no reveal step) with three ratings:
- /Clear/: arrived at understanding, counts toward promotion.
- /Opaque/: still needs work, resets the streak, resurfaces tomorrow.
- /Retire now/: force-retire immediately, regardless of thresholds.
- /Skip/: leave the sentence untouched.

Movement needs *both* enough consecutive =Clear= outcomes (=resurface-drill-promote-exposures=, default 3) *and* a minimum number of days having passed in that mode (=resurface-drill-min-days-per-mode=, default 3, that stops an easy sentence graduating on day one). An =Opaque= outcome resets that streak to zero and always brings the sentence back tomorrow, regardless of its mode's normal interval. If it happens in =maintenance=, the sentence also demotes straight back to =active=, if it got rusty.

You can also batch-retire an entire block at once from its detail view (=R=), rather than only ever retiring one sentence at a time, handy once you have hundreds patterns that have been absorbed.

*** Example Customization
#+BEGIN_SRC emacs-lisp
(setq resurface-drill-intervals '((active . 1) (stabilizing . 4) (maintenance . 14))) ; days between resurfacing, per mode
(setq resurface-drill-promote-exposures 3) ; consecutive Clear outcomes needed to advance a mode
(setq resurface-drill-min-days-per-mode 3) ; mandatory minimum days spent in a mode before advancing
(setq resurface-drill-default-block "General")
#+END_SRC

** Why Leitner and not SM-2 or FSRS?
Those are the right tools for a large quantity of small atomic facts with a clear right/wrong signal, such as vocab, dates, definitions, etc,. 

=Leitner= and =Drill= mode does not have to be a /worse/ version of that, I've instead *re-purposed* them for a different category of tasks, where that signal doesn't exist in the first place, which are *non-retrieval activities*. There are many of these types of activities, two of them are:

- *Whole-file review.* Rereading a 1000-word org file and rating it "bad" because you couldn't recall it perfectly from memory is practically impossible, there's no single "answer" that was right or wrong. We're not practicing active-recall here, but deciding whether you're still comfortable or familiar with the material instead, and seeing that same file again later in the /same/ session because you rated it "bad" is impractical, even moreso when there's many of these files to review in one day.
- *Sentence Drilling.* You're rereading a sentence until you hit an /Aha!/ moment, as a /cognitive activity/, *not* active-recall. There's nothing to grade against a forgetting curve, because nothing was being retrieved in the first place.

** Changelog
- /v0.4.0:/ Drill mode (=resurface-drill=): a parallel review system for rereading short sentences/chunks rather than whole files, built for language learning. No recall grading, items move =active -> stabilizing -> maintenance -> retired=.
- /v0.3.4:/ New =Revised= rating (=C-c l r=) for reviews where you edited or added notes rather than being tested on them. Box and ease factor stay untouched, the review counts as complete, so the file returns on its normal box interval.
- /v0.3.2:/ =Partial= rating (=C-c l p=) for notes too long to finish in one sitting, the file is now marked =Paused=, due again the next day instead of waiting out the full interval.
- /v0.3.1:/ Graduated-file browser (=resurface-leitner-review-graduated=, =G= on the dashboard) to bring individual files back to Box 1 if they become important again.
- /v0.2.3:/ Batch-add multiple files to group through dired mode + automation hooks for extensibility
- /v0.2.2:/ Rename groups + Healthcheck to resolve rename/delete/moved files in a group
- /v0.2.1:/ Random box shuffling & optional question prompts for review
