** What is Resurface?
Resurface is an Emacs package for keeping long-form knowledge familiar over time through scheduled rereading.

Unlike traditional spaced repetition systems, Resurface is *not* designed around active-recall flashcards. Instead it treats rereading as a continuous process of /maintaining familiarity/. Every review contributes *evidence* about how well a note is understood, and that evidence is accumulated over multiple sessions before future review intervals are adjusted.

** Installation with =package-vc-install= (emacs 29+)
 Add the following to your ~init.el~:

 #+BEGIN_SRC emacs-lisp
    (use-package resurface
      :vc (:url "https://github.com/vmargb/resurface.el")
      :bind ("C-c r l" . resurface-leitner)
      :bind ("C-c r i" . resurface-ir))
 #+END_SRC

 #+BEGIN_SRC emacs-lisp
 (setq resurface-index-file "~/notes/.resurface-index.json") ; change location
 (setq resurface-leitner-intervals [1 2 4 8 16 32]) ; set your own ideal intervals
 (setq resurface-leitner-default-group "General") ; default when group not provided

 (setq resurface-enable-ir-mode t)    ; incremental reading

 ;; familiarity Scheduler tuning, these are all optional
 (setq resurface-leitner-ema-alpha-min 0.15)         ; smallest per-rating confidence nudge
 (setq resurface-leitner-ema-alpha-max 0.65)         ; largest, used after a long gap
 (setq resurface-leitner-min-reviews 3)              ; base evidence required at Box 1
 (setq resurface-leitner-min-reviews-box-decay 0.25) ; less evidence needed per box up
 (setq resurface-leitner-variance-weight 1.0)        ; inconsistent ratings need more evidence
 (setq resurface-leitner-promote-threshold 0.80)     ; confidence needed to promote, at Box 1

 (setq resurface-leitner-workload-weight 1.0) ; 0 disables workload-awareness

** Modified Leitner mode
You can read more about the original Leitner system [[https://en.wikipedia.org/wiki/Leitner_system][here]].

The classic Leitner box system has been modified to use what I call a /familiarity scheduler/.

Ratings are instead *Familiar* / *Unfamiliar* rather than Good/Bad, reading back a long-form note is no longer a recall test but about how well you understood the material after rereading it. Two more ratings cover the practical edges of rereading:

- /Partial/: For files too long to finish reading in one sitting. The file is *paused* and comes due again the next day so you can pick up where you left off. Works well with =save-place-mode=.
- /Revised/: For when you *edited* or *added new content*. Box stays untouched, but the review counts as complete, so the file returns on its normal box interval rather than tomorrow.
- /Skip/: Leaves the file in its current box without altering its schedule.

*** How the Familiarity Scheduler works
Below is an oversimplified model of how the algorithm works, to read more go to the [[./docs/familiarity-scheduler.org][docs]].

#+begin_example
Familiarity ratings
        |
        v
Weighted confidence estimate
        |
        v
Desired review interval
        |
        v
Workload-aware scheduler
#+end_example

A single session's rating is too noisy, which is an unreliable measurement for rereading. This was a big weakness of original Leitner. So now, no single Good/Bad rating moves the box directly. Instead:

1. Every rating updates a *confidence score* from -1 to +1.
2. That update is *time-aware*: Rereading something you only just saw barely moves the needle, since you haven't proven anything new, surviving a long gap is real evidence and moves the confidence more.
3. The box only moves once confidence clears a threshold, /and/ enough ratings have landed since the last move.
4. The threshold itself decays for higher boxes too, so promotion gets easier to earn the further up you already are. Demotion is adaptive rather than a flat "back 1 box" or "back to box 1": how far it drops scales with how badly confidence missed the threshold, so one bad session doesn't punish you as hard.
5. Each box is now an *ideal* interval rather than an exact deadline. The scheduler looks at every day around the ideal and self-balances load by picking whichever is least crowded with other reviews. This is actually used in distributed systems. If thousands of servers all retry at exactly 10 seconds, they overload the network.

The explicit "reset to Box 1" action (=r= in the detail/graduated views) always goes straight to Box 1 and clears confidence/variance back to zero, regardless of current standing, which manually overrides existing scheduling.

*** Optional question prompts
Though this is built around reviewing long-form documents, you /can/ *optionally* add specific question prompts with =#+LEITNER_PROMPT:= at the top of an org file to create standard Q&A flashcards(useful for incremental reading). Otherwise it will fallback to your =#+TITLE:=. Or just leave this empty and it will ignore the prompt entirely.


** Incremental Reading mode
Incremental Reading (IR) is a *second, independent* companion, for when the thing you're resurfacing isn't a note file you already wrote, but parts of a book, paper, or article you want to remember.

As a minimal solution it does two things, and deliberately nothing else:

1. *Decides which sources you see today.* Register a PDF, EPUB, or URL with =resurface-ir-add-source= and give it a 0-100 priority. =resurface-ir-start-session= builds a queue from whatever's currently due, shuffled a little for noise and then sorted by priority, so high-priority sources come up more often. The cards you make from each snippet are fed into the same scheduler that =resurface-leitner= uses.

2. *Turn a selection into a card.* IR does not implement a document reader. =resurface-ir-open-function= is called with the source to open it, by default =find-file= for local files (which is all a pdf reader like [[https://codeberg.org/MonadicSheep/emacs-reader][emacs-reader]] needs) and =eww= for URLs to a webpage. Resuming where you left off inside a source is left entirely to Emacs' own =save-place-mode=. While reading, select any passage and run =resurface-ir-capture= (=C-c i c=): it opens a dedicated buffer with the selection dropped in, ready to /reword/ or add =cloze-deletions=. =C-c C-c= sends the result as a brand-new =.org= card under the source's own Leitner and drops you back exactly where you were reading. From that point on the card is a perfectly ordinary Leitner item, reviewed by the same Familiarity Scheduler. And that's it!


 | Keybinding                          | Command                         | Description                                          |
 |--------------------------------------+----------------------------------+-------------------------------------------------------|
 | =M-x resurface-ir=                        | =resurface-ir=                        | Open the source-queue dashboard.                     |
 | =M-x resurface-ir-add-source=             | =resurface-ir-add-source=             | Register a PDF/EPUB/URL and set its priority.        |
 | =M-x resurface-ir-start-session=          | =resurface-ir-start-session=          | Open today's due sources, highest priority first.    |
 | =M-x resurface-ir-capture=                | =resurface-ir-capture=                | Reword the active selection into a Leitner card.     |
 | =M-x resurface-ir-review-finished=        | =resurface-ir-review-finished=        | Browse finished sources bring any back into rotation. |

*** Reading-session keybindings
Bound in the source's buffer once opened via a session or the dashboard (=resurface-ir-reading-minor-mode=):

- =C-c i c=: capture the current selection into a card (see above).
- =C-c i d=: done for now, reschedules the source and moves to the next queued one.
- =C-c i f=: mark the source fully finished, it drops out of the rotation.
- =C-c i s=: skip, leaving the source's schedule untouched.
- =C-c i q=: quit the session, progress so far is saved.

*** Customization
#+BEGIN_SRC emacs-lisp

(setq resurface-ir-capture-directory "~/notes/resurface-ir-cards/") ; where captured cards are written
(setq resurface-ir-default-priority 50)  ; offered when adding a source
(setq resurface-ir-session-max-items 5)  ; nil queues every due source
;; the day-picker, same tuning knobs as Leitner's boxes (see above)
(setq resurface-ir-max-gap-days 14)          ; ideal gap at priority 0
(setq resurface-ir-min-gap-days 1)           ; ideal gap at priority 100
(setq resurface-ir-interval-tolerance 0.3)
(setq resurface-ir-workload-weight 0.3)

;; swap in a different reader, receives the full source alist
(setq resurface-ir-open-function #'my/open-with-pdf-tools-or-nov)
#+END_SRC


** Cloze mode: add cloze-deletions to your cards

Mark any span of text like =The capital of France is {{Paris}}.= and, once =resurface-cloze-mode= is enabled in that buffer, the marked text is masked until the cursor moves into it, then hidden again once point leaves.

 | Keybinding                              | Command                            | Description                                      |
 |------------------------------------------+-------------------------------------+---------------------------------------------------|
 | =M-x resurface-cloze-mode=                    | =resurface-cloze-mode=                    | Toggle hiding/revealing clozes in this buffer.   |
 | =M-x resurface-cloze-dwim=                    | =resurface-cloze-dwim=                    | Cloze the region, or insert an empty cloze at point. |
 | =M-x resurface-cloze-remove-at-point=         | =resurface-cloze-remove-at-point=         | Strip the cloze delimiters around point.         |
 | =M-x resurface-cloze-hide-all=                | =resurface-cloze-hide-all=                | Force every cloze in the buffer shut.            |
 | =M-x resurface-cloze-reveal-all=              | =resurface-cloze-reveal-all=              | Force every cloze in the buffer open.            |

*** Example Customization
#+BEGIN_SRC emacs-lisp
(setq resurface-enable-cloze-mode t) ; require resurface-cloze.el alongside Leitner

(setq resurface-cloze-open "{{")  ; opening delimiter
(setq resurface-cloze-close "}}") ; closing delimiter
(setq resurface-cloze-style 'mask)          ; 'mask (matches hidden length) | 'fixed
(setq resurface-cloze-placeholder "[...]")  ; used when style is 'fixed
(setq resurface-cloze-mask-char ?█)         ; used when style is 'mask
(setq resurface-cloze-hide-delimiters t)    ; nil keeps {{ }} visible as a marker
#+END_SRC

** Changelog
- /v0.3.0: (EMA scheduler)/ Replaced the rolling-history window with an O(1) exponential moving average. Confidence updates are now time-aware (a rating's weight scales with the gap since the last review). Box-move thresholds are now adaptive, the evidence required to move is less for higher boxes and grows with variance, the promotion threshold itself decays for higher boxes, and demotion severity scales with how badly the confidence missed the threshold instead of always dropping back to box 1.
- /v0.2.2: (incremental reading)/ =resurface-ir.el= keeps a priority queue of whole sources (PDFs, EPUBs, web pages) and decides which are due each day via the same scheduler =resurface-leitner= uses. Captures a selection from any reader into a dedicated reword-then-file buffer, filing the result as an ordinary Leitner card under the source's own group.
- /v0.2.1: (cloze deletions)/ New optional companion file, =resurface-cloze.el=. Marks text spans (like =\{\{Paris\}\}=) and hides them behind an overlay placeholder until point moves into them.
- /v0.2.0: (new engine)/ Full rewrite based around a *Familiarity Scheduler*: ratings are now Familiar/Unfamiliar, building a rolling recency-weighted confidence score rather than moving the box on a single rating. Boxes are now ideal intervals, not deadlines, next-review dates are chosen from a small window around the ideal to spread load across quieter days. 
- /v0.1.0: (initial)/ Standard Leitner box implementation with extra features: random box shuffling, rename groups, healthcheck, batch add files through dired, graduated-file-browser, partial and revised ratings and resurface-drill.
