#+TITLE: resurface.el: Reread your Org notes efficiently
#+AUTHOR: vmargb
#+DESCRIPTION: Resurface material for review using a modified Leitner box system.
#+LICENSE: GPL-3.0-or-later

Resurface is an Emacs package that keeps long-form knowledge familiar over time through scheduled rereading.

Unlike traditional spaced repetition systems focused on active recall, Resurface treats rereading as a continuous process of *maintaining familiarity* using an adaptive /Familiarity Scheduler/.

-----

* Features
- *Familiarity-Based Scheduling:* Rates notes by using a unique familiary-based scheduler designed for long-form material.
- *Incremental Reading (IR):* Queue PDFs, EPUBs, or URLs by priority and capture snippets to review later or create flashards.
- *Cloze-Deletions:* Mask important text spans you want to recall with ~{{example}}~ when the cursor moves over them (or with =resurface-cloze-reveal-all=)

-----

* Installation

Requires Emacs 29+. Add the following to your ~init.el~:

#+BEGIN_SRC emacs-lisp
(use-package resurface
  :vc (:url "https://github.com/vmargb/resurface.el")
  :bind (("C-c r l" . resurface-leitner)
         ("C-c r i" . resurface-ir)))
#+END_SRC

* Core Leitner Mode

** Review Ratings
- *Familiar / Unfamiliar:* Standard review ratings that update long-term confidence.
- *Partial:* For long files. Pauses the document and resumes it tomorrow (pairs well with ~save-place-mode~).
- *Revised:* Used when editing/adding new content. Completes the review without altering box schedule.
- *Skip:* Leaves the file in its current box without updating schedule.

** Keybindings
| Keybinding                             | Command                            | Description                              |
|----------------------------------------+------------------------------------+------------------------------------------|
| ~M-x resurface-leitner~                  | ~resurface-leitner~                  | Open the group dashboard.                |
| ~M-x resurface-leitner-add-group~        | ~resurface-leitner-add-group~        | Add a new group.                         |
| ~M-x resurface-leitner-add-file~         | ~resurface-leitner-add-file~         | Add current buffer to a group.           |
| ~M-x resurface-leitner-start-session~    | ~resurface-leitner-start-session~    | Start a review session for due files.    |
| ~M-x resurface-leitner-review-graduated~ | ~resurface-leitner-review-graduated~ | Browse graduated files (reset to Box 1). |
| ~M-x resurface-leitner-healthcheck~      | ~resurface-leitner-healthcheck~      | Resolve deleted/renamed/moved files.     |

** Customization & Tuning

(setq resurface-index-file "~/notes/.resurface-index.json")

* Companion Modules

** Incremental Reading (IR) Mode
Register PDFs, EPUBs, or web pages as priority sources. Then extract selected text directly into new Leitner review cards.

*** Dashboard Commands
| Keybinding                       | Command                      | Description                                  |
|----------------------------------+------------------------------+----------------------------------------------|
| ~M-x resurface-ir~                 | ~resurface-ir~                 | Incremental reading dashboard.               |
| ~M-x resurface-ir-add-source~      | ~resurface-ir-add-source~      | Register PDF/EPUB/URL with priority (0–100). |
| ~M-x resurface-ir-start-session~   | ~resurface-ir-start-session~   | Open today's due sources by priority.        |
| ~M-x resurface-ir-capture~         | ~resurface-ir-capture~         | Reword active selection into a card.         |
| ~M-x resurface-ir-review-finished~ | ~resurface-ir-review-finished~ | Browse and restore finished sources.         |

*** Reading Session Commands (~resurface-ir-reading-minor-mode~)
- ~C-c i c~: Capture selection into a new card.
- ~C-c i u~: Update a previous card in the same group.
- ~C-c i d~: Done for now (reschedules source, moves to next item).
- ~C-c i f~: Mark source fully finished.
- ~C-c i s~: Skip without altering schedule.
- ~C-c i q~: Quit session and save progress.

*** Customization
#+BEGIN_SRC emacs-lisp
(setq resurface-enable-ir-mode t)
(setq resurface-ir-capture-directory "~/notes/resurface-ir-cards/")
(setq resurface-ir-default-priority 50)
(setq resurface-ir-session-max-items 5)
(setq resurface-ir-max-gap-days 14)
(setq resurface-ir-min-gap-days 1)
(setq resurface-ir-interval-tolerance 0.3)
(setq resurface-ir-workload-weight 0.3)

;; optional custom reader interface
(setq resurface-ir-open-function #'my/open-with-pdf-tools-or-nov)
#+END_SRC

** Cloze Mode
Mask text regions formatted like ~{{cloze}}~. Text is hidden behind placeholders until the cursor moves inside.

| Keybinding                          | Command                         | Description                              |
|-------------------------------------+---------------------------------+------------------------------------------|
| ~M-x resurface-cloze-mode~            | ~resurface-cloze-mode~            | Toggle cloze masking in current buffer.  |
| ~M-x resurface-cloze-dwim~            | ~resurface-cloze-dwim~            | Cloze region or insert empty delimiters. |
| ~M-x resurface-cloze-remove-at-point~ | ~resurface-cloze-remove-at-point~ | Strip cloze delimiters around point.     |
| ~M-x resurface-cloze-hide-all~        | ~resurface-cloze-hide-all~        | Force hide all clozes.                   |
| ~M-x resurface-cloze-reveal-all~      | ~resurface-cloze-reveal-all~      | Force reveal all clozes.                 |

*** Customization
#+BEGIN_SRC emacs-lisp
(setq resurface-enable-cloze-mode t)
(setq resurface-cloze-open "{{")
(setq resurface-cloze-close "}}")
(setq resurface-cloze-style 'mask) ; 'mask | 'fixed
(setq resurface-cloze-placeholder "[...]")
(setq resurface-cloze-mask-char ?█)
(setq resurface-cloze-hide-delimiters t)
#+END_SRC

* Technical Details: How the Familiarity Scheduler Works

For more information on how the scheduler works: [[./docs/familiarity-scheduler.org][docs/familiarity-scheduler.org]].
A very simplified explanation of the features:

1. *Confidence Scoring:* Ratings shift a file's confidence score (-1.0 to +1.0).
2. *Time-Aware Weighting:* Ratings after long gaps carry significantly more weight than ratings shortly after a previous review.
3. *Gradual Promotion & Adaptive Demotion:* Files move up boxes only after reaching a confidence threshold over multiple reviews. Demotions drop files proportionally to the drop in confidence rather than resetting blindly.
4. *Load balancing:* The system shifts reviews within a tolerance window to avoid daily review spikes.
